One menu bar. Every utility you reach for.

MenuUtils is a modular macOS menu-bar platform that consolidates the power-user tools you keep open all day — system monitoring, clipboard history, meeting transcription, app uninstaller, and Xcode cleanup — into a single, calm, native app.

What's inside

Six modules, one host app. Each lives in the menu bar and can be turned on or off independently.

📊 System Monitor

CPU, memory, disk, and GPU at a glance. Fan speed and temperature sensors on the direct build. Purge memory to reclaim RAM.

🌐 Network Monitor

Live upload/download throughput, per-interface breakdowns, and week/month history with compaction tiers.

📋 Clipboard Manager

Searchable clipboard history with sensitive-content detection, pinning, and a global ⌘⇧V shortcut that works everywhere.

🎙️ Meeting Transcription

Live on-device speech-to-text for meetings. Audio never leaves your Mac — transcription runs locally with the Speech framework.

🗑️ App Uninstaller

Move applications to Trash along with their support files. User-selected folders only — no hardcoded path scanning.

🧹 Xcode Cleaner

Reclaim disk space from DerivedData and related caches. Reaches them only through a bookmark you grant explicitly.
